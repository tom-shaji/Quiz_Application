# Simple Quiz Application

A simple command-line Quiz Application built with Python. 
It contains 10 multiple-choice questions, tracks your score, and provides a performance message at the end.

## Features
- 10 multiple-choice questions with options A, B, C, and D.
- Immediate feedback on correct or wrong answers.
- Input validation to handle invalid choices (only A, B, C, and D are accepted).
- Final score calculation including total questions, correct/wrong answers, and percentage.
- Evaluates performance with a custom message based on score.
- Option to easily restart and take the quiz again.

## Requirements
- Python 3.x
- No external libraries are needed (uses only standard built-in modules).

## How to Run
1. Open a terminal or command prompt in the directory containing the project files.
2. Run the application using the following command:
   ```bash
   python main.py
   ```
